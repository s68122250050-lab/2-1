## Recursive Two-Pointer

Pseudocode
1.	ตั้งตัวชี้ left ไว้ที่ต้นอาร์เรย์ และตัวชี้ right ไว้ที่ท้ายอาร์เรย์
2.	ถ้า left เลื่อนมาเจอหรือเลย right แล้ว ให้หยุดทำงาน (จบการทำงาน)
3.	ถ้าตัวเลขที่ตำแหน่ง left เป็นเลขคู่อยู่แล้ว ให้เลื่อน left ไปทางขวา 1 ตำแหน่ง แล้วเรียกเมธอดตัวเองซ้ำ
4.	ถ้าไม่ใช่ข้อ 3 แต่ตัวเลขที่ตำแหน่ง right เป็นเลขคี่อยู่แล้ว ให้เลื่อน right มาทางซ้าย 1 ตำแหน่ง แล้วเรียกเมธอดตัวเองซ้ำ
5.	ถ้าไม่เข้ากรณีไหนเลย (คือ left เป็นเลขคี่ และ right เป็นเลขคู่) ให้สลับค่าทั้งสองตำแหน่งกัน แล้วเลื่อนตัวชี้ทั้งสองเข้าหากันฝั่งละ 1 ตำแหน่ง จากนั้นเรียกเมธอดตัวเองซ้ำ


## Iterative Two-Pointer

1.	ตั้งตัวชี้ left ไว้ที่ต้นอาร์เรย์ และตัวชี้ right ไว้ที่ท้ายอาร์เรย์
2.	วนทำซ้ำตราบใดที่ left ยังมาไม่ถึง right:
–	ถ้าตัวเลขที่ตำแหน่ง left เป็นเลขคู่อยู่แล้ว ให้เลื่อน left ไปทางขวา 1 ตำแหน่ง
–	ไม่เช่นนั้น ถ้าตัวเลขที่ตำแหน่ง right เป็นเลขคี่อยู่แล้ว ให้เลื่อน right มาทางซ้าย 1 ตำแหน่ง
–	ไม่เช่นนั้น (left เป็นคี่, right เป็นคู่) ให้สลับค่าทั้งสองตำแหน่ง แล้วเลื่อนตัวชี้ทั้งสองเข้าหากันฝั่งละ 1 ตำแหน่ง
3.	เมื่อ left มาถึง right แล้ว ให้หยุดทำงาน


## Extra Array

Pseudocode
1.	สร้างอาร์เรย์ใหม่ขึ้นมาขนาดเท่ากับอาร์เรย์เดิม
2.	วนอ่านอาร์เรย์เดิมรอบแรกตั้งแต่ต้นจนจบ ถ้าเจอเลขคู่ ให้นำไปใส่ในอาร์เรย์ใหม่เรียงต่อกันไปเรื่อยๆ
3.	วนอ่านอาร์เรย์เดิมอีกรอบตั้งแต่ต้นจนจบ ถ้าเจอเลขคี่ ให้นำไปใส่ในอาร์เรย์ใหม่ต่อจากเลขคู่ทั้งหมด
4.	คืนค่าอาร์เรย์ใหม่


# วิเคราะห์

# Time Complexity
ทั้งสามวิธีเท่ากันคือ O(n) เพราะแต่ละวิธีอ่าน/ตรวจสมาชิกแต่ละตัวเพียงครั้งเดียวหรือไม่กี่ครั้งเท่านั้น

# Space Complexity
Recursive Two-Pointer ใช้ O(n) จาก Call Stack, Iterative Two-Pointer ใช้เพียง O(1) เพราะไม่ต้องเก็บอะไรเพิ่มนอกจากตัวชี้ ส่วน Extra Array ใช้ O(n) เพราะต้องสร้างอาร์เรย์ใหม่ขึ้นมาอีกชุด

# จำนวนครั้งของการสลับข้อมูล
Recursive Two-Pointer และ Iterative Two-Pointer สลับข้อมูลสูงสุด n/2 ครั้งเท่ากัน (สลับเมื่อฝั่งซ้ายเป็นคี่และฝั่งขวาเป็นคู่) ส่วน Extra Array ไม่มีการสลับข้อมูลเลย เพราะเขียนค่าลงอาร์เรย์ใหม่โดยตรงแทน

# การเปลี่ยนแปลงอาร์เรย์เดิม (In-place)
Recursive Two-Pointer และ Iterative Two-Pointer แก้ไขอาร์เรย์เดิมโดยตรง (in-place) ส่วน Extra Array ไม่แก้ไขอาร์เรย์เดิม แต่ต้องใช้อาร์เรย์เพิ่มขึ้นมาอีกชุด

# ความเป็น Stable Algorithm
Recursive Two-Pointer และ Iterative Two-Pointer ไม่ Stable เพราะการสลับตำแหน่งจากปลายทั้งสองข้างเข้าหากันทำให้ลำดับเดิมภายในกลุ่มเปลี่ยนไป ส่วน Extra Array เป็น Stable เพราะอ่านค่าตามลำดับเดิมแล้วคัดแยกใส่อาร์เรย์ใหม่โดยไม่สลับตำแหน่งกันเอง

# สรุป
ถ้าต้องการประหยัดหน่วยความจำและแก้ไขอาร์เรย์เดิม (in-place) ควรเลือก Iterative Two-Pointer เพราะมี Time Complexity เท่ากับวิธีอื่นแต่ใช้พื้นที่เพียง O(1) และไม่มีความเสี่ยงเรื่อง Stack Overflow แต่ถ้าโจทย์ต้องการรักษาลำดับเดิมของสมาชิกในแต่ละกลุ่ม (Stable) ต้องเลือก Extra Array แม้จะเสียพื้นที่เพิ่มก็ตาม ส่วน Recursive Two-Pointer ให้ผลลัพธ์เหมือน Iterative แต่มีต้นทุนแฝงจาก Call Stack จึงเหมาะสำหรับสาธิตแนวคิดเวียนเกิดมากกว่าใช้งานจริงกับข้อมูลขนาดใหญ่
