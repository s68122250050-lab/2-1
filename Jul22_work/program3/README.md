## Recursive Counting

Pseudocode
1.	เริ่มต้นที่ตัวอักษรตัวแรก พร้อมตัวนับสระ = 0 และตัวนับพยัญชนะ = 0
2.	ถ้าตรวจครบทุกตัวอักษรแล้ว ให้เปรียบเทียบว่าจำนวนสระมากกว่าจำนวนพยัญชนะหรือไม่ แล้วตอบผลลัพธ์ (จบการทำงาน)
3.	ดูตัวอักษรตัวปัจจุบัน (แปลงเป็นตัวพิมพ์เล็กก่อน)
–	ถ้าไม่ใช่ตัวอักษร (เช่น ตัวเลขหรือช่องว่าง) ให้ข้ามไปตรวจตัวถัดไปโดยไม่นับ
–	ถ้าเป็นสระ (a, e, i, o, u) ให้เพิ่มตัวนับสระอีก 1
–	ถ้าเป็นพยัญชนะ ให้เพิ่มตัวนับพยัญชนะอีก 1
4.	เรียกเมธอดตัวเองซ้ำเพื่อตรวจตัวอักษรตัวถัดไป โดยส่งค่านับที่อัปเดตแล้วไปด้วย


## Iterative Counting

Pseudocode
1.	ตั้งตัวนับสระ = 0 และตัวนับพยัญชนะ = 0
2.	วนอ่านตัวอักษรในสตริงทีละตัวจนครบ (แปลงเป็นตัวพิมพ์เล็กก่อนดู)
–	ถ้าไม่ใช่ตัวอักษร ให้ข้ามไปตัวถัดไปโดยไม่นับ
–	ถ้าเป็นสระ ให้เพิ่มตัวนับสระอีก 1
–	ถ้าเป็นพยัญชนะ ให้เพิ่มตัวนับพยัญชนะอีก 1
3.	เมื่อวนครบทุกตัวแล้ว เปรียบเทียบว่าตัวนับสระมากกว่าตัวนับพยัญชนะหรือไม่ แล้วตอบผลลัพธ์


# วิเคราะห์

# Time Complexity ของทั้งสองวิธี
เท่ากันคือ O(n) เพราะต่างก็ต้องอ่านตัวอักษรครบทุกตัวในสตริงอย่างน้อยหนึ่งครั้ง

# Space Complexity ของทั้งสองวิธี
ต่างกันชัดเจน Recursive Counting ใช้ O(n) เพราะต้องเก็บ Call Stack ลึกเท่ากับความยาวสตริง ส่วน Iterative Counting ใช้เพียง O(1) เพราะใช้แค่ตัวแปรนับสระและพยัญชนะสองตัวเท่านั้น

# จำนวน recursive calls
Recursive Counting เรียกเมธอดตัวเองทั้งหมด n+1 ครั้ง (ครั้งสุดท้ายคือ Base Case) ส่วน Iterative Counting ไม่มีการเรียกซ้ำเลย ใช้ลูปแทน

# ความเสี่ยงของ StackOverflowError
Recursive Counting มีความเสี่ยง หากสตริงยาวมาก (โดยทั่วไป Java จะเริ่มเสี่ยงเมื่อความลึกระดับหลักหมื่นถึงหลักแสน ขึ้นกับขนาด stack ที่ตั้งไว้) ส่วน Iterative Counting ไม่มีความเสี่ยงนี้เลย เพราะไม่ได้ใช้ Call Stack เพิ่ม

# ขนาดข้อมูลที่เหมาะสมสำหรับแต่ละวิธี
Recursive Counting เหมาะกับสตริงขนาดเล็ก-กลาง หรือใช้เพื่อการศึกษาแนวคิดการเวียนเกิด ส่วน Iterative Counting ใช้ได้กับข้อมูลทุกขนาด รวมถึงข้อมูลขนาดใหญ่มากโดยไม่มีความเสี่ยง

# สรุป
ทั้งสองวิธีมี Time Complexity เท่ากันคือ O(n) แต่ Iterative ประหยัดพื้นที่หน่วยความจำกว่ามาก (O(1) เทียบกับ O(n)) และไม่มีความเสี่ยงเรื่อง Stack Overflow จึงเหมาะสมกว่าสำหรับการใช้งานจริง ส่วน Recursive เหมาะสำหรับสตริงขนาดเล็กหรือใช้เพื่อฝึกความเข้าใจแนวคิดการเวียนเกิด
