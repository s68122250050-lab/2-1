## Reverse and Compare

Pseudocode
1.	แปลงสตริงทั้งหมดให้เป็นตัวพิมพ์เล็ก และตัดช่องว่างกับเครื่องหมายวรรคตอนออก เหลือแต่ตัวอักษรและตัวเลข
2.	นำสตริงที่สะอาดแล้วมาสร้างเป็นสตริงกลับด้าน
3.	เปรียบเทียบสตริงที่สะอาดแล้ว กับสตริงกลับด้าน
4.	ถ้าทั้งสองสตริงเหมือนกัน แสดงว่าเป็น Palindrome ให้ตอบว่า true ถ้าไม่เหมือนกันให้ตอบว่า false


## Recursive Two-Pointer

Pseudocode
1.	ตั้งตัวชี้ left ไว้ที่ตัวอักษรตัวแรก และตัวชี้ right ไว้ที่ตัวอักษรตัวสุดท้าย
2.	ถ้า left เลื่อนมาเจอหรือเลย right แล้ว แสดงว่าตรวจครบทุกคู่และตรงกันหมด ให้ตอบว่า true (จบการทำงาน)
3.	เปรียบเทียบตัวอักษรที่ตำแหน่ง left กับ right ถ้าไม่เหมือนกัน ให้ตอบว่า false ทันที (ไม่ต้องตรวจต่อ)
4.	ถ้าตัวอักษรคู่นี้เหมือนกัน ให้เลื่อน left เข้ามาทางขวา 1 ตำแหน่ง และเลื่อน right เข้ามาทางซ้าย 1 ตำแหน่ง แล้วเรียกเมธอดตัวเองซ้ำเพื่อตรวจคู่ถัดไป

## วิเคราะห์
## กรณีที่สตริงเป็น Palindrome
ทั้งสองวิธีต้องประมวลผลจนครบ เพราะไม่มีจุดไหนที่ตัวอักษรไม่ตรงกันเลย Reverse and Compare อ่านครบทุกตัว O(n) ส่วน Recursive Two-Pointer ตรวจครบทุกคู่ O(n) เท่ากัน

## กรณีที่ตัวอักษรคู่แรกไม่ตรงกัน
Reverse and Compare ยังคงต้องสร้างสตริงย้อนกลับทั้งหมดก่อนจึงจะเปรียบเทียบได้ ใช้เวลา O(n) เท่าเดิม แต่ Recursive Two-Pointer หยุดทำงานได้ทันทีในเวลา O(1) เพราะเปรียบเทียบตัวอักษรทีละคู่จากด้านนอกเข้ามา

## Best-case Time Complexity
Reverse and Compare คือ O(n) เสมอ ไม่ว่ากรณีใด ส่วน Recursive Two-Pointer คือ O(1) เมื่อคู่แรกไม่ตรงกัน

## Worst-case Time Complexity
ทั้งสองวิธีคือ O(n) เท่ากัน (กรณีสตริงเป็น Palindrome จริง)

## Space Complexity
Reverse and Compare ใช้ O(n) เพราะต้องสร้างสตริงใหม่ทั้งสตริงที่ทำความสะอาดแล้วและสตริงกลับด้าน ส่วน Recursive Two-Pointer ใช้ O(n) เช่นกัน แต่มาจาก Call Stack เพียงอย่างเดียว ไม่ได้สร้างสตริงใหม่เพิ่ม
ความสามารถในการหยุดทำงานก่อนครบทุกตัวอักษร: Reverse and Compare ทำไม่ได้ ต้องประมวลผลจนจบเสมอ แต่ Recursive Two-Pointer ทำได้ทันทีที่พบตัวอักษรคู่ที่ไม่ตรงกัน

## สรุป
Recursive Two-Pointer มีประสิทธิภาพดีกว่าในทางปฏิบัติ เพราะสามารถหยุดทำงานได้ทันทีเมื่อพบว่าไม่ใช่ Palindrome (early exit) และไม่ต้องเสียพื้นที่สร้างสตริงใหม่ ส่วน Reverse and Compare เขียนง่ายกว่าและอ่านเข้าใจง่าย แต่สิ้นเปลืองเวลาและพื้นที่มากกว่าเมื่อสตริงมีขนาดใหญ่และไม่ใช่ Palindrome
